# Internal implementation audit

Detailed verification records are retained in each project's `docs/VERIFIED_SCOPE.md` and `evidence/` directory. The repository-wide audit index is maintained in [docs/internal/REPOSITORY_AUDIT.md](docs/internal/REPOSITORY_AUDIT.md).

This maintenance file is not part of the public portfolio presentation. The public website focuses on project context, the user's role, methods, technologies and deliverables. Syntax checks and fixture-based unit tests must not be described as proof of production readiness.
