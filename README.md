# Panupong Intasan — Portfolio

Public portfolio for Business Analyst, System Analyst, and Data Analyst opportunities.

Website: https://intasan.github.io/portfolio/

## Files

- `index.html`: responsive portfolio and 17 project case studies. The `PROJECTS` array is the source for project details and filters.
- `ppe-case-study.html`: a summarized BA take-home case study, labeled as a proposed solution.
- `CV_Panupong_Intasan.pdf`: one-page CV matching the website's target roles and availability.
- `favicon.svg`, `social-card.png`: identity and sharing assets.
- `robots.txt`, `sitemap.xml`: crawler metadata.
- `QA.md`: verification scope and limitations.

## Maintenance

Edit the project-specific role, scope, result, and limitation fields together. Keep featured cards and the static project list consistent with `PROJECTS` when changing titles or adding/removing projects. Never label concept diagrams or design mockups as screenshots. Link to repositories for source/documentation; do not present localhost addresses as public demos.

Update the website and CV together when education, availability, contact details, or experience changes. The current education wording indicates graduation documentation in progress; it does not claim an issued degree certificate.

No build dependencies are required. GitHub Pages serves the repository root.
