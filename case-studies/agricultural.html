Project overview

รวบรวมราคาสินค้าเกษตรจาก DIT, NABC และตลาดไท พร้อม Dashboard ที่อ่าน PostgreSQL โดยตรง

My responsibilities

ออกแบบการรวบรวมและตรวจสอบข้อมูล ปรับ Pipeline และ Dashboard ให้เปรียบเทียบราคาอย่างมีเงื่อนไข

Business problem & objectives

ราคาจากแต่ละแหล่งมีชื่อสินค้า หน่วย ช่วงเวลา และประเภทการวัดต่างกัน จึงต้องจัดโครงสร้างร่วมและตรวจข้อมูลก่อนนำไปแสดงผล เป้าหมายคือรวบรวมข้อมูลหลายแหล่งโดยรักษาความหมายของราคาและไม่เปรียบเทียบสินค้าคนละหน่วย

System architecture & database design

Collector ของ DIT, NABC และตลาดไท → Validation และ Deduplication → PostgreSQL ด้วย UPSERT → Streamlit Dashboard โดย Apache Airflow จัดลำดับงาน

observation_key ใช้ระบุข้อมูลสังเกตการณ์เพื่อลดการเพิ่มแถวซ้ำ ส่วน pipeline_runs เก็บสถานะรอบประมวลผล Dashboard อ่านฐานข้อมูลโดยตรงและกรองตามแหล่ง สินค้า หน่วย ประเภทการวัด และวัน

Testing & recorded results
