Project overview

แนวคิดระบบรวบรวมและวิเคราะห์ราคาทองคำ เพื่อวางกรอบการทำงานด้าน Data Integration และการวิเคราะห์ข้อมูล

My responsibilities

จัดทำกรอบแนวคิดและหน้าอธิบายโครงการด้านการรวบรวมและวิเคราะห์ราคาทองคำ

Concept scope

กรอบแนวคิดศึกษาการรวบรวมราคาทอง จัดเตรียมข้อมูล และนำเสนอเพื่อสนับสนุนการวิเคราะห์ Repository ปัจจุบันมี README และหน้า HTML แนะนำโครงการ

Concept only: Airflow, PostgreSQL, Feature Engineering, Machine Learning และ Dashboard เป็นแนวทางที่ต้องพัฒนาต่อ ยังไม่มี Source ขององค์ประกอบเหล่านี้ใน Repository จึงไม่มีผลพยากรณ์หรือค่าประเมินโมเดลที่นำมาแสดง

Concept workflow

  1. กำหนดโจทย์ข้อมูล
  2. วางกรอบการรวบรวม
  3. วางแนวทางวิเคราะห์

Results & deliverables

เอกสารแนวคิดและหน้าแนะนำโครงการ ยังไม่มี ETL, Airflow DAG, PostgreSQL, ML หรือ Dashboard ที่รันได้ใน Repository ปัจจุบัน
