Proposed technical scope

Objective: explore a traceable gold-price dataset for analysis. Proposed flow: approved market sources → raw observations → validation and normalization → analytical storage → features → chronological evaluation → dashboard.

  • Data sources: candidate sources require access, licensing, timestamp and unit checks; no integrated source is verified.
  • Architecture / ETL / database: design direction only; no executable implementation or schema is supplied.
  • Feature engineering: proposed indicators and market covariates require reproducible input series; no generated feature dataset is verified.
  • ML: no trained model or forecast output is verified. No model family is claimed as implemented.
  • Evaluation methodology: proposed chronological holdout or walk-forward validation, leakage checks, and a simple baseline before reporting MAE/RMSE. No score is available.
  • Dashboard: concept presentation only; no live analytical dashboard is verified.
