BA Take-home Assignment · Proposed Solution

AI PPE Inspection

ตัวอย่างการวิเคราะห์ความต้องการระบบตรวจอุปกรณ์ป้องกันส่วนบุคคล ณ ทางเข้าโรงงาน

สถานะ: ข้อเสนอสำหรับกรณีศึกษา ยังต้องยืนยันกับลูกค้า ไม่ใช่ระบบที่ติดตั้งใช้งานจริง

1. เป้าหมายและขอบเขต

ตรวจ Helmet, Mask, Vest และ Gloves แจ้งเตือนเมื่อสวมไม่ครบ และค้นหาเหตุการณ์ย้อนหลังได้ โดยแยกผลครบ ไม่ครบ และไม่มั่นใจ

2. คำถามสำคัญก่อนออกแบบ

  1. เป้าหมายและเกณฑ์ตรวจรับคืออะไร?
  2. กฎ PPE ต่างกันตามจุดตรวจหรือกลุ่มผู้เข้าอย่างไร?
  3. มีกี่กล้อง จำนวนคนผ่าน และข้อจำกัดด้านแสง/การบังกันเท่าไร?
  4. กรณีมองไม่เห็น PPE ใครต้องตรวจทาน?
  5. ต้องแจ้งเตือนใคร ผ่านช่องทางใด และภายในเวลาใด?
  6. เก็บภาพและ Log อะไรบ้าง ใครมีสิทธิ์ และเก็บนานเท่าไร?
  7. ใช้ข้อมูลสถานที่จริงชุดใดทดสอบ AI และใครลงนามตรวจรับ?

เอกสารต้นฉบับจัดคำถาม 24 ข้อ ครอบคลุม Business, Operations, Camera, AI, Alert, Log, Privacy และ UAT

3. Functional Requirements

  1. รับภาพกล้องและแสดงสถานะการเชื่อมต่อ
  2. ตรวจจับบุคคลในพื้นที่ ROI
  3. ประเมิน PPE เป็น Present / Missing / Uncertain
  4. กำหนดกฎ PPE ตามจุดตรวจ
  5. แจ้งเตือนพร้อมรายละเอียด PPE ที่ขาด
  6. เจ้าหน้าที่ตรวจทาน พร้อมบันทึกการตัดสิน
  7. บันทึก Event Log และค้นหาย้อนหลัง
  8. กำหนดสิทธิ์และติดตามสถานะกล้อง/เครือข่าย

4. Non-functional Requirements

กำหนดและตกลง Performance, Availability, Accuracy ราย PPE, Security, Retention, Reliability และ Usability ก่อน Baseline ข้อเสนอเวลาแจ้งเตือนและ Uptime ในเอกสารเป็นเป้าหมายร่าง ไม่ใช่ผลทดสอบ

5. Workflow

  1. บุคคลเข้า ROI และตรวจคุณภาพภาพ
  2. ประเมิน PPE ตาม Policy
  3. ครบ: แสดงสถานะตามกฎ / ไม่ครบ: แจ้งเตือน / ไม่มั่นใจ: ส่งตรวจทาน
  4. เจ้าหน้าที่ดำเนินการและบันทึกผล
  5. หากกล้องล่ม ให้ใช้ขั้นตอนตรวจด้วยคนตาม SOP

6. ตัวอย่าง Acceptance Criteria / UAT

  • ขาดหมวกชัดเจน → แสดง Helmet Missing และแจ้งเตือน
  • มือถูกบัง → แสดง Uncertain ไม่สรุปว่าไม่ได้ใส่ถุงมือ
  • กล้อง Offline → แสดงข้อผิดพลาดและแนวทางตรวจด้วยคน
  • ผู้ใช้ไม่มีสิทธิ์ดู Log → ปฏิเสธการเข้าถึง

7. MVP และสิ่งที่ต้องยืนยัน

เสนอเริ่มหนึ่งจุดตรวจ ครอบคลุม 4 PPE, Manual Review, Alert, Event Log และสิทธิ์ผู้ใช้ ก่อนขยายหลายจุด ต้องยืนยันเกณฑ์ Accuracy, จำนวนกล้อง, ภาระงาน, Retention, งบประมาณ และผู้อนุมัติ
