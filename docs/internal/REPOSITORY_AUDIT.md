# Internal Repository Audit

This file is retained for project traceability. It is not linked from the public portfolio.

The source audit covers the 18 repositories reviewed in November 2026. The excluded repository was not opened or modified.

## Evidence locations

Each repository retains its own:
- `docs/VERIFIED_SCOPE.md`
- `evidence/source-audit.json`
- `evidence/STATUS.md`
- Relevant runtime logs and screenshots under `evidence/`

## Public presentation policy

The public portfolio presents project context, the user's role, methods, technologies and deliverables. Detailed environment limitations and repository-wide audit tables are kept out of the public portfolio navigation. Project descriptions must remain accurate and must not imply production readiness, real transactions, model quality or user acceptance without supporting evidence.

## Review scope

The previous public audit page has been retired. Use the per-repository evidence files above as the authoritative record; do not treat syntax checks or fixture-based unit tests as proof of complete real-world operation.
